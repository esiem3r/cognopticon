# Behavioral Insights

Cognopticon is built on a behavioral claim: unfinished work fails when state becomes invisible.

Patterns it detects:

- duplicate restart loops
- context swamps
- high concept / low closure
- stale active projects
- sleeping giants
- verification gaps
- public release blockers
- unsafe agent handoffs

The intervention is not motivation. It is state visibility plus bounded next action.

Cognopticon turns invisible project state into graph state, beliefs, proposals, and missions.
