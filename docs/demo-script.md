# Demo Script

1. Start the sanitized demo.

```bash
npm install
npm run dev:demo
```

2. Show the graph universe and self-node.
3. Hover a node and show the projected glance card.
4. Click a node and show the NodeCockpit.
5. Show the cognition rail: goals, proposals, missions, daemon status, and orchestrator state.
6. Focus the duplicate Operator Studio cluster.
7. Generate a mission from a proposal.
8. Focus Launchable Tool and show LaunchPort plus safe fallback.
9. Explain the safety line: the browser can generate packets; the daemon can only run allowlisted local actions inside configured roots; worker agents stay outside the daemon boundary.
10. Explain local mode:

```bash
npm run local:init -- --roots "/path/to/projects"
npm run scan
npm run analyze
npm run local
```

Closing line: Cognopticon is not a TODO app. It is a local cognitive instrument that turns unfinished work into navigable state and agent-ready transformations.
