# Code of Conduct

Cognopticon contributors are expected to keep the project useful, kind, and careful.

## Expected Behavior

- Be precise, respectful, and direct.
- Assume good intent while still reviewing code and claims critically.
- Keep disagreement focused on behavior, evidence, and maintainability.
- Protect other people's private workspace data, logs, paths, and security reports.
- Make room for contributors with different experience levels.

## Unacceptable Behavior

- Harassment, threats, insults, or sustained disruptive behavior.
- Publishing private data, secrets, daemon tokens, or vulnerability details without consent.
- Bad-faith issues, pull requests, or reviews that create noise without improving the project.
- Attempts to bypass local safety boundaries or pressure maintainers to weaken them.

## Scope And Enforcement

This code applies to project spaces, including issues, pull requests, discussions, community channels, and release coordination. Maintainers may edit, hide, or remove content; close threads; block participants; or decline contributions that violate these expectations.

Report conduct concerns through the support or security channels described in `SUPPORT.md` and `SECURITY.md`.
