# Support

Cognopticon is a local-first project. Support requests should be reproducible without exposing your private workspace.

## Questions

Open a GitHub discussion or issue when public discussion is safe. Include your operating system, Node version, command run, and a sanitized description of the behavior.

## Bugs

Use the bug report template and include:

- what you expected
- what happened
- exact command output, trimmed to the relevant lines
- whether the public demo or a local profile was involved
- screenshots only when they do not reveal private project names, paths, tokens, or logs

## Private Data Safety

Do not post:

- `.cognopticon/` profile state
- daemon tokens
- private paths
- generated local workspace JSON
- logs containing secrets
- screenshots that reveal private projects

If a report needs private detail, first ask for a safe reporting channel.

## Security

For vulnerabilities, follow `SECURITY.md`. Do not publish exploit details in public issues.
